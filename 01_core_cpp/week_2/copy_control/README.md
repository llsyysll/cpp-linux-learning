# 拷贝控制

## 浅拷贝（Shallow Copy）

**定义**：只复制指针值（地址），不复制指针指向的内容。

**问题**：
1. 两个对象指向同一块内存 → 修改一个影响另一个
2. 析构时 double free → 程序崩溃
3. 悬空指针（一方释放后，另一方仍持有地址）

**什么时候发生**：
- 编译器自动生成的默认拷贝构造函数
- 编译器自动生成的默认拷贝赋值运算符

## 深拷贝（Deep Copy）

**定义**：复制指针指向的实际数据，分配新的内存。

**实现**：
- 在拷贝构造函数中分配新内存，复制数据
- 在拷贝赋值运算符中同样处理

## 何时需要自定义拷贝控制

**三/五法则（Rule of Three/Five）**：
> 如果类需要自定义析构函数，则一定需要自定义拷贝构造函数和拷贝赋值运算符。

| 成员函数 | 何时需要自定义 |
|---------|---------------|
| 析构函数 | 管理资源（堆内存/文件/锁） |
| 拷贝构造函数 | 管理资源时（深拷贝） |
| 拷贝赋值运算符 | 管理资源时（深拷贝） |
| 移动构造函数 | 需要移动语义优化 |
| 移动赋值运算符 | 需要移动语义优化 |

## 口诀

> **有析构，必有拷贝构造和拷贝赋值**
> **有拷贝构造，必有拷贝赋值（反之亦然）**

## 核心对比

| 特性 | 浅拷贝 | 深拷贝 |
|------|--------|--------|
| 复制内容 | 指针值（地址） | 指针指向的数据 |
| 内存 | 共享同一块内存 | 各自独立内存 |
| double free | ❌ 会 | ✅ 不会 |
| 修改影响 | 互相影响 | 互不影响 |
| 性能 | 快 | 慢（需要分配内存） |
| 安全性 | 低 | 高 |


# 拷贝赋值运算符要点

### 四步标准写法
1. **自赋值检测**：`if (this == &other) return *this;`
2. **释放旧资源**：`delete[] data_;`
3. **分配新资源**：`data_ = new char[...];`
4. **复制数据**：`strcpy(data_, other.data_);`

### 返回值
- 返回 `*this`（引用）
- 支持链式赋值 `a = b = c`

### 自赋值陷阱
- 不检测自赋值会导致：释放 → 访问已释放内存 → 未定义行为
- 三种解决方式：自赋值检测、拷贝再释放、临时变量

### 规则三/五
- 定义了析构函数、拷贝构造函数、拷贝赋值运算符中的一个，通常需要定义全部

# 其他
### 关于this/other的对比
|------|------|------|
|this	|当前对象的指针	|0x2000（指向 s2）|
|&s2	|调用对象的地址	|0x2000|
|other	|被复制对象的引用|引用 s1|
|&other	|被复制对象的地址|0x1000（等价于 &s1）|
|this == &other|检查是否同一个对象|自我赋值时为 true|

### this/other例子
假设对象在内存中的地址：
s1 的地址：0x1000
s2 的地址：0x2000

s2 = s1;  
函数调用时：
this = &s2 = 0x2000
other是 s1 的引用
&other = &s1 = 0x1000
this != &other → 0x2000 != 0x1000 → true

s1 = s1;
函数调用时：
this = &s1 = 0x1000
other是 s1 的引用
&other = &s1 = 0x1000
this != &other → 0x1000 != 0x1000 → false

### 赋值运算符模板
```cpp
MyString& operator=(const MyString& other) {
    // ========== 第一步：自我赋值检查 ==========
    // 检查是否是自我赋值（如 s1 = s1）
    if (this == &other) {
        // 如果是同一个对象，直接返回，不做任何操作
        return *this;
    }
    
    // ========== 第二步：释放原有资源 ==========
    // 删除当前对象原有的动态内存
    delete[] data_;  // 释放旧的内存
    
    // ========== 第三步：复制新资源 ==========
    // 根据 other 的大小分配新内存
    size_ = other.size_;                    // 复制大小
    data_ = new char[size_ + 1];            // 分配新内存（+1 给 '\0'）
    strcpy(data_, other.data_);             // 复制字符串内容
    
    // ========== 第四步：返回当前对象 ==========
    // 返回当前对象的引用，支持链式赋值
    return *this;  // *this 就是当前对象（s2）
}
```
### MyString& operator=(const MyString& other)函数签名解析
|部分|含义|
|------|------|
|MyString&|返回值类型：返回当前对象的引用，支持链式赋值（如 a = b = c）|
|operator=|函数名：赋值运算符重载|
|(const MyString& other)|参数：被复制对象的常量引用，避免拷贝，只读访问|
|other|被复制对象的引用（在调用 s2 = s1 时，other 引用 s1）|
