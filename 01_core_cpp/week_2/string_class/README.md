# MyString 类设计要点

## 核心规则（三五法则）
C++11 起，定义了以下任何一个，通常需要定义全部：
1. 析构函数
2. 拷贝构造函数
3. 拷贝赋值运算符
4. 移动构造函数
5. 移动赋值运算符

## 各函数触发时机速查表

| 函数 | 触发场景 |
|------|----------|
| 拷贝构造 | `MyString s4(s2);` 或 `MyString s4 = s2;` |
| 拷贝赋值 | `s5 = s3;` (s5 已存在) |
| 移动构造 | `MyString s6(std::move(s2));` (临时对象/显式移动) |
| 移动赋值 | `s7 = std::move(s3);` |
| 析构函数 | 对象离开作用域或被 `delete` |

## 深拷贝 vs 浅拷贝
- **浅拷贝**（默认）：只复制指针，两个对象指向同一块内存 → **double free**
- **深拷贝**（我们实现）：复制整个数据，每个对象独立管理内存
