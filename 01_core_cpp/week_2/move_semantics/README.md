# 移动语义核心知识点

## 1. 左值 vs 右值

| | 左值 (lvalue) | 右值 (rvalue) |
|--|--------------|---------------|
| 本质 | 有持久地址的表达式 | 临时值，没有持久地址 |
| 能取地址 | ✅ 能 | ❌ 不能 |
| 有名字 | ✅ 有 | ❌ 没有（临时） |
| 示例 | 变量 `int a = 10;` | 字面量 `42`、`a + b` |

## 2. 右值引用 `&&`

- 只能绑定到右值
- 用于识别可被移动的资源
- 延长临时对象的生命周期

```cpp
int&& rref = 42;        // ✅ 绑定到右值
int a = 10;
int&& rref2 = a;        // ❌ 不能绑定到左值
int&& rref3 = std::move(a); // ✅ 使用 move 转成右值
