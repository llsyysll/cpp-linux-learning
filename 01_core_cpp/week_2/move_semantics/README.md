# 移动语义核心知识点

## 1. 左值 vs 右值

| | 左值 (lvalue) | 右值 (rvalue) |
|--|--------------|---------------|
| 本质 | 有持久地址的表达式 | 临时值，没有持久地址 |
| 能取地址 | ✅ 能 | ❌ 不能 |
| 有名字 | ✅ 有 | ❌ 没有（临时） |
| 示例 | 变量 `int a = 10;` | 字面量 `42`、`a + b` |

## 2. 右值引用 `&&`

- 只能绑定到右值
- 用于识别可被移动的资源
- 延长临时对象的生命周期

```cpp
int&& rref = 42;        // ✅ 绑定到右值
int a = 10;
int&& rref2 = a;        // ❌ 不能绑定到左值
int&& rref3 = std::move(a); // ✅ 使用 move 转成右值
```

# 移动语义总结

## 一、左值 vs 右值

| 类型 | 定义 | 示例 | 能否取地址 |
|------|------|------|-----------|
| **左值 (lvalue)** | 有持久地址的对象 | 变量名、`*p`、`arr[0]` | ✅ 能 |
| **右值 (rvalue)** | 临时对象，即将销毁 | 字面量、临时对象、`std::move(x)` | ❌ 不能 |

## 二、移动语义核心

**解决的问题**：拷贝临时对象时深拷贝开销大，其实可以直接"偷"资源。

| 操作 | 数据操作 | 开销 | 源对象状态 |
|------|---------|------|-----------|
| 拷贝构造 | 深拷贝 | O(n) | 不变 |
| 移动构造 | 指针转移 | O(1) | 置空（可析构） |
| 拷贝赋值 | 深拷贝 | O(n) | 不变 |
| 移动赋值 | 指针转移 | O(1) | 置空（可析构） |

## 三、移动构造/赋值的关键

1. **参数必须是右值引用**：`String(String&& other)`
2. **必须 `noexcept`**：保证容器在扩容时可以安全移动（否则用拷贝）
3. **窃取资源后，把源对象置空**：防止析构时 double free
4. **自赋值检测**：移动赋值也需要检测 `this != &other`

## 四、`std::move` 的本质

> `std::move` 不移动任何东西，只是一个 **类型转换**：把左值强制转成右值引用，让编译器优先匹配移动版本。

```cpp
// 伪代码实现
template<typename T>
std::remove_reference_t<T>&& move(T&& t) {
    return static_cast<std::remove_reference_t<T>&&>(t);
}
