## 核心区别速记

| 特性        |   指针        | 引用 |
|------       |------        |------|
| 必须初始化   | 否，可为空    | 是，必须绑定 |
| 能否重新指向 | 能            | 不能|
| 占用内存    | 是（8字节）    | 视编译器而定，通常不占 |
| 安全性      | 可能为空/野指针| 安全（绑定后一直有效） |
| 语法        | `*p` 解引用    | 直接使用，像普通变量 |

## 今日易错点
1. `int& ref = a;` ref 是 a 的别名，对 ref 赋值就是修改 a
2. 引用不能重新绑定：`ref = b;` 是把 b 的值赋给 a，不是让 ref 指向 b
3. 绝不能返回局部变量的引用（悬垂引用）

- int* const p：指针本身不可变
- const成员函数不能修改成员变量
- const对象只能调用const成员函数
